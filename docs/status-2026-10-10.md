# AM Agent Fleet 项目状态简报（2026-10-10）

## 一句话

多 Agent 舰队平台 MVP 已开发完成并打首个发布版 **v0.1.0**，运维文档齐备，
**下一步是在阿里云 ECS 上做首次真实部署与规模化验收**。

## 平台能力（已落地，全部经真实业务用例验证）

- **任务池全链路**（ADR-0010）：task/loop 分离、竞争领取（≤3 并行）、强制验收、
  打回同 thread 续跑、人机同构交付（人通过贴飞书链接交付，与 agent 产物同等验收）
- **舰队协作**：舰队指挥官 agent 自主拆解任务、spawn 子任务给 worker、
  整合多路交付产出简报（`agent_spawn` / `agent_message` 工具，零改上游源码）
- **业务系统接入**：agent 凭用户对话中提供的凭据，用内置 http 工具自主对接
  任意数据网站（已实测读通 timeline 看板：7 看板 469 卡）；平台不固化任何
  业务系统能力
- **生命周期**：YAML 定义 agent（注册/版本化/拉起/休眠/唤醒续跑/销毁）、
  cron 定时建池任务、审计留痕
- **Console**：Fleet Loop 看板 + 验收台 + Registry + Task/Thread 详情，
  人机操作统一入口
