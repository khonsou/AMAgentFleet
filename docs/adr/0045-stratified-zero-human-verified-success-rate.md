# ADR-0045：分层零人工验收通过率与可扩展基础评测集

- **状态**：已接受
- **日期**：2026-11-02
- **补充／取代**：取代 ADR-0044 第 1、9 条中以 VGH 作为唯一北极星和发布改善门的决定；其余有界执行、独立验收、单 Agent 对照、维护者 accept 和禁止自动开发继续有效。

## 背景

第一轮真实 single／multi 对照中，VGH 因主动人工时间多次触发 0.001 秒下限而失去区分度。功能评分和 P0 有改善，但不能据此宣称人力效率提升。单纯改为 Human-not-in-the-loop 比例也不充分：直接失败但没有求人同样属于零人工，不能代表平台价值。

当前 `core-v1` 在 single 与修复后的 multi 上均已达到零人工验收通过，单一 case 已出现天花板。平台需要能持续加入基础能力 case 的集合，并以同一口径衡量正确性、自治性、稳定性和成本，而不是针对某次实验临时换指标。

## 决定

1. **平台主北极星改为分层零人工验收通过率（SZ-VSR）**。每次运行只有同时满足下列条件才计为一次成功：任务提交和配置冻结后零人工介入；独立评分器、环境最终状态或可执行测试验收通过；安全约束通过；在预先冻结的 Token、费用和墙钟预算内完成。
2. **人工介入定义**：人工续写、唤醒、重试、重派、补工具、改配置、修答案、补数据或其他帮助任务通过的补救均计入。初始任务提交和独立的事后影子审计不算执行介入；审计若参与修复，则该次运行失败。
3. **分层而不是事后加权**：case 预先标注难度、能力类别、风险、Optimization／Holdout 和固定权重。跨层汇总权重在实验前冻结，不得为了候选获胜而修改；样本不足时报告各层原始成功数／运行数，不用总分掩盖不确定性。
4. **VGH 降级为诊断指标**：继续记录真实主动人工时间与 VGH，但接近零的计时下限不得再单独决定发布。Token、费用、墙钟和每次零人工验收成功成本同样作为诊断或独立预算门，不揉成一个加权总分。
5. **集合发布门**：候选必须在同 case、同数据、同模型 Profile 的 single 对照上严格改善 SZ-VSR；不得出现单 case 质量、安全或成本护栏回退。Holdout 必须覆盖，候选关键 case 还需满足预声明的零人工 `pass^k` 重复稳定门。小样本或缺证据只能报告观测结果，不能宣称严格 improve。
6. **建立 `platform-basic-v1` 首批集合**：保留 `core-v1` 双源协作题；新增 `time-now-v1` 时间获取全流程、`multi-echo-v1` 基础多 Agent 自动唤醒与汇总、`external-info-v1` 运行时外部信息获取。每个 case 独立版本化题面、预算、难度、拆分与确定性验收，后续 case 只追加新目录和集合登记，不复制启动器。
7. **外部能力不绑定业务网站**：`external-info-v1` 在运行时注册受控 HTTP Provider，通过真实 Capability Plane 发现、解析和调用。每次运行生成新的观测值，且核对真实 invocation 证据；不得把 Timeline 或任何具体第三方网站硬编码为平台评测能力。
8. **时间证据来自平台**：`time-now-v1` 不只检查自然语言答案，必须核对 Fleet Thread／Checkpoint 中的真实时间戳、运行时间窗口和 Asia/Shanghai 换算，防止凭模型内部时间猜中。
9. **保留有界维护者门**：集合运行仍只能由维护者显式触发；不得因报告生成自动开发、自动合并、自动验收或启动下一轮。旧运行产物可按原口径保留，不得追认为新北极星下的改善。

## 后果

- 正面：北极星直接对应“任务可托付”，避免 VGH 在接近零人工时失真；基础 case 可逐渐增加，并分别观察能力覆盖、稳定性、成本和单 Agent 对照。
- 负面／约束：需要维护更多任务、独立评分器与 Holdout；重复运行增加模型费用。集合覆盖和 `pass^k` 未满足时发布门会更严格，但这是有意保留的证据要求。
- 本批边界：只建立指标、首批 case、执行与集合汇总能力及离线回归；不因场景文件存在就宣称真实模型全流程已经通过。

## 已考虑的备选

- **继续只用 VGH**：否决，接近零人工时计时误差被无限放大。
- **只用零人工介入率**：否决，失败但不求人可能被误记为自治。
- **所有维度揉成一个综合分**：否决，权重可操纵，且可能用低成本掩盖质量或安全回退。
- **立即采用 Human Time Horizon 作为每轮开发门**：暂缓，长期价值高但需要大量可信人类时长基线；可在真实任务积累后另写 ADR 增加 H80-ZH。
